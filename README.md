# SnippetVault

SnippetVault is a planned desktop application for storing, organizing, and finding reusable snippets.

## Project structure

- `main.py` — application entry point.
- `controller.py` — MVC-inspired coordination layer.
- `models.py` — domain data models.
- `ui.py` — desktop presentation layer.
- `database.py` — persistence infrastructure.
- `search.py` — snippet search services.
- `clipboard.py` — clipboard integration.
- `utils.py` — shared helpers.
- `tests/` — automated tests.
- `assets/` — visual and static application assets.

No functionality has been implemented yet.
